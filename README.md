# AI Study Assistant 🤖📚

## About the Project

AI Study Assistant is a simple AI-powered application that helps students learn and study.

## Features

- Explain difficult topics
- Summarize information
- Generate quiz questions
- Provide AI-powered responses

## Technologies Used

- Python
- Streamlit
- Google Gemini AI

## How It Works

1. Enter your Gemini API Key.
2. Enter a topic or question.
3. Select an option.
4. Click Generate Answer.
5. Get an AI-generated response.
